# Price Validation Process Documentation

The price validation process is a crucial step in the data pipeline, designed to parse, clean, validate, and format the raw price information collected by the web scraper. It ensures that every product has a reliable and correctly structured price before it moves to later stages like analysis and upload.

The process is initiated by running the following command:

```bash
npm run validate:prices
```

This command executes the `scripts/validate-prices.js` script, which orchestrates the entire workflow.

---

## 1. The Validation Flow

The process can be broken down into four main steps:

#### Step 1: Reading Input Data
The `validate-prices.js` script begins by locating and reading all the raw JSON files generated by the scraper.

-   **Input Location:** `storage/datasets/default/`
-   **Action:** The script reads each `.json` file in this directory, which contains an array of scraped product items.

#### Step 2: Processing Each Item's Price
For every product item found in the input files, the script delegates the core validation logic to the `processAllPrices` function from `src/1_scraping/validation/priceParcer.js`.

```javascript
// From: scripts/validate-prices.js
for (const item of items) {
    // ...
    const mockSiteConfig = { conversionRate: 1 }; 
    const result = await processAllPrices(item, mockSiteConfig);
    
    allProcessedItems.push({
        ...item,
        priceAnalysis: result // The validation result is added here
    });
    // ...
}
```

#### Step 3: Core Logic in `priceParcer.js`
The `processAllPrices` function performs a detailed analysis for each price associated with an item.

1.  **Parse String to Number:** It uses the `mapPrice` utility to strip currency symbols (`₺`, `$`, etc.) and non-numeric text from the raw price string (e.g., `"799.99 TL"`) and convert it into a clean number (e.g., `799.99`).
2.  **Determine Currency:** It identifies the currency of the price.
3.  **Format for Display:** It creates a locale-aware, formatted price string for display purposes (e.g., `₺799,99`).
4.  **Set Validation Flags:** Based on the parsing result, it sets several boolean flags (`priceValid`, `priceisUnset`, `priceScrapeError`) that define the validity of the price.

#### Step 4: Writing Output
After all items from all files have been processed, the script aggregates them into a single array and writes the result to a new file.

-   **Output File:** `artifacts/price-validated.json`
-   **Action:** This file contains all the original product data, with each item now enriched with a `priceAnalysis` object.

---

## 2. When is a Price Valid vs. Invalid?

The system uses a set of clear rules to determine price validity. The final status is captured in the `priceAnalysis` object.

#### A Price is Considered **VALID** if:
An item's overall `priceValid` flag is `true` only if **all** of its associated prices are successfully parsed into a numeric value that is **greater than zero**.

```javascript
// from: src/1_scraping/validation/priceParcer.js
const priceValid = parsedPrices.length > 0 && parsedPrices.every(p => typeof p.numericValue === 'number' && p.numericValue > 0);
```

**Example of a Valid Price:**
-   **Raw Value:** `"799.99 TL"`
-   **Parsed `numericValue`:** `799.99`
-   **Result:** `priceValid: true`

#### A Price is Considered **INVALID** if:
The `priceValid` flag will be `false` if any of the following conditions are true. The system provides additional flags to specify the reason for the invalidity.

1.  **The Price is Zero (`priceisUnset: true`)**
    -   This occurs when the parsed `numericValue` is exactly `0`. It often indicates a placeholder value on the website.
    -   **Example:** A price of `"0 TL"` results in `priceValid: false` and `priceisUnset: true`.

2.  **The Price Fails to Parse (`priceScrapeError: true`)**
    -   This happens if the `mapPrice` function cannot extract a number from the string (e.g., the string is "Call for Price").
    -   The `numericValue` defaults to `0` in this case.
    -   **Example:** A price of `"On Sale"` results in `priceValid: false` and `priceScrapeError: true`.

3.  **The Price Array is Empty**
    -   If a product has no `price` array or the array is empty, it will result in `priceValid: false`.

## 3. Input and Output Structure

The process transforms raw scraped data into validated and enriched data.

### Input Example (A single item from `storage/datasets/default/`)
The input is the direct output from the scraper. The `price` field contains a raw string value.

```json
{
  "id": "bbcb205a...",
  "title": "Kadın Suni Deri Omuz Çantası",
  "link": "https://www.defacto.com.tr/kadin-suni-deri-omuz-cantasi-3213023",
  "price": [{ "value": "799.99 TL", "currency": "TL" }],
  "img": [ "..." ]
}
```

### Output Example (The same item in `artifacts/price-validated.json`)
The output item includes the new `priceAnalysis` object, which contains the parsed numeric value, validation flags, and a display-ready price string.

```json
{
  "id": "bbcb205a...",
  "title": "Kadın Suni Deri Omuz Çantası",
  "priceAnalysis": {
    "parsedPrices": [{
        "value": "799.99 TL",
        "currency": "TL",
        "numericValue": 799.99,
        "unsetPrice": false,
        "displayPrice": "₺799,99"
    }],
    "priceValid": true,
    "priceisUnset": false,
    "priceScrapeError": false
  }
}
```
